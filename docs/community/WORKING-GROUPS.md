# Робочі групи та можливості долучення

Групи нижче – **пропонована структура самоорганізації**, а не вже сформовані команди із призначеними керівниками. Будь-яка людина може запропонувати іншу групу або спільне завдання.

| Напрям | Чим допомогти на старті |
| --- | --- |
| **Громадянська участь і фасилітація** | Перевірити [інструкцію для громадянина](START-HERE.md), провести пробне неупереджене уточнення трьох ідей, описати бар'єри для людей без GitHub |
| **Конституція, право, самоврядування** | Рецензувати Хартію, перевіряти межі повноважень країв і громад, розділити консультативні процедури та офіційні звернення |
| **Права людини, приватність і безпека** | Моделювати загрози, перевірити згоду, захист меншин, анонімізацію, правила збереження інформації та оскарження |
| **Економіка й перевірка результатів** | Розробити відтворювані методики оцінки альтернатив, витрат, нерівномірних наслідків і критеріїв успіху |
| **Протокол, AI, MCP і веб** | Доповнити UAGP-схеми, протестувати взаємодію різних AI, зробити інтерфейс простим і доступним |
| **Громади, транспорт, енергетика, освіта, послуги** | Запропонувати перевірні суспільні кейси із публічних джерел без персональних даних |
| **Комунікації, переклад, доступність** | Написати зрозумілі пояснення українською, перевірити доступність, додати переклади й офлайн-матеріали |

## Порядок приєднання

Знайдіть відповідну задачу в [Issues](https://github.com/ailubes/uagp/issues) або відкрийте нову із вказанням напряму. Представитися можна лише тим, що ви добровільно хочете повідомити про себе – місце роботи, повне ім'я та контакти не є обов'язковими для публічного технічного обговорення. Не залишайте приватних телефонів чи адрес у GitHub.

Заінтересованість не означає автоматичного доступу до персональних даних або адміністративних функцій. Права на репозиторій, огляд і майбутню інфраструктуру надаються окремо за критеріями компетентності, безпеки й конфлікту інтересів.

## Перший спільний практичний напрям

[UAGP Living Practice 90](../strategy/LIVING-PRACTICE-90.md) запрошує робочі групи запропонувати методику пілота, безпечні приклади, партнерські спільноти, можливих людських координаторів і незалежних рецензентів. Ми не припускаємо, що учасники вже погодилися: добровільність, зрозуміла мета, базові показники та право на критику передують кожному старту.

## Перші спільні результати

Відкритий перелік питань до Хартії; три незалежно розібрані громадянські кейси; висновок про юридичні межі OIDC-ідентичності; аудит моделі приватності; документований шлях участі без GitHub; публічний огляд перших PR #7–#10.

Успіх вимірюється не кількістю рекламних підписників, а якістю розглянутих ідей, прозорістю процедур, відтворюваністю оцінок та тим, чи можуть різні люди реально впливати на проєкт.
