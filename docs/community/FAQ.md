# UAGP – відповіді на поширені запитання

### Це політична партія, державний орган чи рух за скасування демократії?

Ні. UAGP – відкритий дослідницький громадянський проєкт. Він пропонує експериментувати зі способами суспільної участі, але не підмінює Конституцію, вибори, місцеве самоврядування чи законні компетенції. Критика його архітектури вітається.

### Що таке «алгоритмічний уряд»?

У наших робочих документах – набір інструментів, які допомагають людям, громадам та законним органам аналізувати проблеми, порівнювати варіанти й відстежувати виконання. Це не автономний суверен із правом наказувати громадянам.

### «Край» уже є офіційною одиницею нового устрою?

Ні. Це пропозиція для громадського обговорення. У поточному прототипі крайовий рівень може бути лише логічною координацією, без нових владних повноважень.

### Чи треба мати ChatGPT, Claude або платну модель?

Ні. Ідеї можна готувати самостійно. Принцип Bring Your Own AI дає свободу вибору моделі, але не створює обов'язку користуватися AI або платити за нього.

### Чи всі чати передаватимуться в UAGP?

Ні. Приватна розмова – не офіційна справа й не публічна пропозиція. Для майбутньої системи потрібне окреме підтвердження змісту та обсягу даних; поточний sandbox не приймає реальні приватні справи.

### Як зареєструватися, щоб долучитися?

Публічні матеріали можна читати без реєстрації. Наразі Issues та коментарі працюють через GitHub-акаунт. Незалежний self-hosted OIDC-вхід UAGP запланований, але не запущений; його не пов'язуватимемо із Wesfin ID. Без GitHub уже можна підготувати публічну чернетку локально.

### Чи можу я використати псевдонім?

Для загальнодоступних обговорень можливе псевдонімне представлення. Для майбутніх юридично значущих процедур може бути потрібна окрема законна перевірка особи й повноваження. Простий OIDC-акаунт сам по собі не підтверджує громадянство, вік, територіальну належність чи право голосувати.

### Чи означають лайки або голоси GitHub, що пропозицію схвалило суспільство?

Ні. GitHub відображає активність учасників проєкту, а не репрезентативне волевиявлення. Наукова, правова, правозахисна й суспільна перевірки потрібні окремо.

### Хто ухвалює зміни?

Зміни до GitHub-проєкту ухвалюють відповідальні maintainers за публічними правилами з можливістю заперечення. Вони не мають мандата ухвалювати рішення за громади або Україну. Хартія залишається відкритою для критичного перегляду.

### Як не допустити, щоб проєкт захопила одна компанія чи група?

Потрібні відкритий протокол, незалежна ідентичність, прозора структура спільноти, контроль ключів і фінансування, конфлікт-оф-інтересів, альтернативні реалізації та публічна можливість переглянути рішення. Ці механізми ще треба юридично й організаційно закріпити, а не лише задекларувати.

### Чи можна вже тестувати портал із реальними даними?

Ні. PR #7–#10 містять локальні демонстраційні інструменти з тестовою авторизацією. Вони не є публічними державними послугами та не придатні для приватних персональних справ.

### Яку першу практичну користь я можу принести?

Описати проблему й бажаний результат за [шаблоном](PROPOSAL-TEMPLATE.md), перевірити один факт, аргументовано розкритикувати статтю Хартії або допомогти зробити правила участі зрозумілими людині без технічного досвіду.
