# Перший відкритий воркшоп UAGP: сценарій фасилітації

**Матеріал для підготовки, не анонс реальної запланованої події.** Підходить для малої групи учасників без обов'язкової реєстрації, платних AI або технічних знань.

## Мета зустрічі

Перевірити, чи здатні люди з різним досвідом описати конкретну проблему, зрозуміти механізм її розгляду, поставити критичні питання та не втратити власний голос, коли AI допомагає робити зведення.

## Пропонована тривалість: 90 хвилин

| Час | Що відбувається |
| --- | --- |
| 0–10 хв | Представлення UAGP як дослідницького проєкту; окремо – що не є державним сервісом |
| 10–20 хв | Пояснення правил приватності, добровільності й права не погоджуватися |
| 20–40 хв | У малих групах 2–3 конкретні суспільні проблеми без імен чи приватних випадків |
| 40–55 хв | Уточнення бажаного результату; формулювання альтернатив та перевірних фактів |
| 55–70 хв | Незалежна критика: кого може зачепити рішення, що невідомо, які права ризикують |
| 70–80 хв | Перегляд того, чи коректно задокументовано думку кожного учасника |
| 80–90 хв | Явне рішення авторів, чи бажають вони опублікувати саме погоджену публічну версію; збір зауважень до самого процесу |

## Правила ведення

Фасилітатор не має готового «правильного» рішення. Не фотографуйте списки учасників чи особисті записи без окремої згоди. Не записуйте на аудіо без дозволу кожної зачепленої людини. Будь-яку зведену пропозицію перед публікацією поверніть на погодження автору. Залиште місце для заперечення, зокрема проти використання AI.

Для демонстрації працюйте із синтетичними даними: перетини розкладів транспорту, умовні комунальні послуги, вигадані сценарії. Не використовуйте реальні індивідуальні адміністративні справи або приватні тексти.

## Вихідні матеріали

Знеособлений опис проблеми; бажаний результат; перелік невідомих фактів; щонайменше дві альтернативи; потенційні правові та соціальні ризики; заперечення учасників; оцінка зрозумілості процесу. Публічний запис робиться лише за згодою відповідних авторів.

## Чого воркшоп не робить

Не визначає репрезентативну позицію громади, не проводить вибори, не схвалює конституційні зміни, не зобов'язує орган влади щось реалізувати. Це спосіб випробувати й поліпшити саму процедуру участі.
