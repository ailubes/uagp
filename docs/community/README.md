# UAGP: простір співтворення

**Ласкаво просимо до відкритої громадянської ініціативи, яка досліджує нові механізми участі людей в управлінні Україною.**

UAGP не створює нову державу, не є органом влади, політичною партією або державним електронним сервісом. Це відкритий майданчик для проєктування, критики, перевірки та пілотування ідей демократичного алгоритмічного врядування. Мета – створити умови, за яких потреби громадян визначають розвиток управлінських інструментів, а не навпаки.

## Чотири способи участі

**Громадянин:** описати проблему у своїй громаді, сформулювати бажаний результат, заперечити проти сумнівного рішення, запропонувати спосіб виміряти його ефект.

**Дослідник або фахівець:** перевірити цифри, іноземний досвід, економічні припущення, ризики для прав людини, правові обмеження.

**Розробник або дизайнер:** описати протокол, протестувати API, створити доступний інтерфейс або провести аудит безпеки.

**Громадська організація або громада:** запропонувати процес відкритої консультації чи добровільний лабораторний пілот, не видаючи UAGP за офіційне рішення.

## Що ще не готове

Немає загальнодоступного бойового порталу, окремого діючого OIDC-входу для громадян UAGP, підтвердженої правової процедури офіційного подання чи громадянського голосування. Демонстраційні PR #7–#10 залишаються проєктним кодом на перевірці. У GitHub обговорення є технічним процесом спільноти, а не виборами або волевиявленням від імені населення України.
