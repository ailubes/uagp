# Перевірка готовності до відкритого запуску

Стан на 22.11.2026: **публічна документація та GitHub-обговорення доступні; бойовий громадянський сервіс UAGP НЕ запущено**. Це контрольний перелік, а не звіт про вже виконані вимоги.

## Для публічної консультації в GitHub

- [ ] Остаточно перевірені та схвалені зрозумілі умови участі, приватності й модерації.
- [ ] Призначено відповідальних за публічні обговорення та їхні конфлікти інтересів.
- [ ] Схвалено правила використання текстових і програмних внесків та ліцензії.
- [ ] Є задокументований шлях повідомлення про вразливість без публікації секретів.
- [ ] Окремо оголошено, що GitHub потребує акаунта і не репрезентує всіх громадян.
- [ ] Готові відповіді на типові питання, засоби доступності й можливість зібрати аргументовані заперечення.
- [ ] Зафіксовано, які обіцянки щодо строків, рішень і юридичного статусу проєкт НЕ надає.

## Перед окремим публічним вебпорталом

- [ ] Самостійно розгорнутий UAGP OIDC issuer із безпековими налаштуваннями, окремими ключами, резервуванням і відновленням.
- [ ] Відповідальний контролер даних, правові підстави обробки, політика зберігання і видалення, права суб'єкта даних.
- [ ] Окрема автентифікація, авторизація та мінімізація даних; тестові токени видалено з виробничого середовища.
- [ ] Профілювання, автоматична публікація й юридично значущі дії заборонені за замовчуванням.
- [ ] Захищена реєстрація, відновлення акаунта, антибот-захист без виключення легітимних користувачів.
- [ ] Незалежний security review, accessibility review, threat model, incident response та спостережуваність.
- [ ] Сумісний MCP із належною авторизацією й окремим погодженням повноважень.
- [ ] Законні маршрути для офіційних процедур перевірено й упроваджено або чітко відключено.
- [ ] Доступний канал участі без GitHub і без платної мовної моделі.

## Перед будь-якою процедурою голосування

- [ ] Правова підстава для виду волевиявлення і компетентний орган.
- [ ] Перевірка виборчих чи інших критеріїв участі, незалежна від простого OIDC-входу.
- [ ] Гарантії таємниці та свободи волевиявлення там, де це потрібно, аудит і процедура оскарження.
- [ ] Заборона видавати GitHub-зірки, кліки чи лайки за офіційний результат.

Поки пункт не виконаний, його не слід описувати як готову функцію.
