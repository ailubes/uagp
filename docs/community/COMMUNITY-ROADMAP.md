# Дорожня карта відкритої участі UAGP

Це **пропонована послідовність**. Відмітка «підготовлено» стосується документів та GitHub, а не працюючої системи публічних адміністративних звернень.

## Фаза A. Відкриті засади та чесний вхід

**Підготовлено в Draft PR спільноти:** зрозуміла сторінка «З чого почати», шаблон ідеї, принципи, процес розгляду, інструкції групам, правила фасилітації, FAQ, матеріали для запрошення, архітектурне рішення про незалежний OIDC.

**Потребує рішення:** затвердити публічну редакцію текстів, застосовувати обрані відкриті ліцензії до власних матеріалів і перевіряти права зовнішніх авторів, визначити відповідальних за модерацію та інциденти, призначити контакт для приватних звернень про безпеку. Поки цього немає, не обіцяти, що існує повноцінна громадська організація або цілодобова підтримка.

## Стратегічний напрям SG-01: UAGP Living Practice 90

Паралельно з публічним обговоренням Хартії й технічними PR готуємо **90-денну дослідницьку програму** із двома або трьома добровільними діючими спільнотами. Спочатку виявляємо їхні теперішні практики та базові показники, далі разом тестуємо людську координацію, безпечне уточнення ідей, добровільний внесок і змістовний зворотний зв'язок. Достовірне порівняння, незалежна критика й рішення «продовжити / переробити / зупинити» є обов'язковими, а дата старту залежить від партнерів та перевірки ризиків.

[SG-01 – повний план](../strategy/LIVING-PRACTICE-90.md) · [шаблон ініціативи](../strategy/PILOT-CARD-TEMPLATE.md).

## Фаза B. Перша відкрита консультація

Оприлюднити запрошення, зібрати зауваження до Хартії, запропонувати принаймні три безпечні суспільні тест-кейси. Мати можливість заявити незгоду, залишити альтернативу та бачити, хто і чому схвалив текст проєкту.

Існуючий канал: GitHub Issues. Він не охоплює всіх громадян; участь людей без GitHub має бути підтримана через зручний альтернативний інструмент до широкого публічного запуску.

## Фаза C. Незалежна цифрова ідентичність і доступний портал

Підняти **окремий самостійно розгорнутий OIDC-провайдер UAGP**, не пов'язаний з Wesfin. Забезпечити безпечну реєстрацію, відновлення доступу, згоду, доступність, незалежну систему авторизації, вимоги безпеки та процедуру видалення даних. Читання публічних матеріалів не повинно вимагати реєстрації.

UAGP вебпортал і remote MCP мають використовувати єдині відкриті правила, але не вимагати одного постачальника мовної моделі. Вхід через OIDC не є перевіркою права на голосування.

## Фаза D. Перевірні консультації та альтернативні реалізації

Відстежуваний статус ініціативи, перевірка джерел, порівняння альтернатив, відкриті зауваження, окремі експертні оцінки, автоматична класифікація з правом апеляції. Обов'язкові незалежний огляд упереджень та приватності, відкрита інформація про помилки та можливість працювати без AI.

## Фаза E. Добровільні лабораторні пілоти

Дві незалежні тестові громади, обмежені набори синтетичних або публічних даних, відсутність змін чинних державних реєстрів. Для переходу до справжньої громади потрібні партнерські рішення, законна підстава, безпекова перевірка та відповідальна людина.

## Показники якості, а не PR

Частка ідей із зрозумілим статусом і причиною; кількість аргументованих альтернатив; частка отриманого зворотного зв'язку; доступність для людей без платного AI; відсутність витоків; якість незалежних перевірок; фактичне виправлення виявлених помилок. Жодна з цих метрик не доводить представництво всього суспільства.

## Перед оголошенням широкого запуску

Перевірити [публічний контрольний перелік](PUBLIC-LAUNCH-CHECKLIST.md). Не плутати технічний GitHub-прототип із готовим урядовим сервісом.
