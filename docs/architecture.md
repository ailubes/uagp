# Архітектура UAGP

## Вихідна ідея

UAGP – відкрита дослідницька архітектура федерації автономних вузлів громад і, за потреби, крайових координаторів. Національний рівень надає спільний каталог довіри й технічних стандартів, але не отримує автоматично централізованого сховища всіх персональних даних.

## Основні компоненти

**CitizenGateway** – взаємодія з громадянином і доступні способи звернення.

**ConversationService** – мовна модель, яка ставить уточнення та формулює пропозиції, але не має прямого доступу до владних інструментів.

**ProposalRegistry** – структуровані картки пропозицій, їхня історія та статуси.

**LegalIntake / JurisdictionRouter** – визначення типу справи та компетентного органу; за невизначеності звернення передається людині.

**AuthorityRegistry** – машиночитні посилання на чинні правові повноваження відповідальних органів.

**PolicyBundle** – підписаний набір правил, обмежень, дозволених інструментів і вимог людського погодження.

**ToolGateway** – незалежний від LLM контроль дозволених дій, підписів, типів даних і класів ризику.

**FederationGateway** – підписаний, мінімізований обмін подіями між вузлами громад.

**AuditLedger** – перевірна історія рішень, технічних версій і дій.

## Межі довіри

Приватний діалог ≠ офіційна справа ≠ публічна пропозиція ≠ технічна зміна. Кожна сутність має окремі правила доступу і зберігання.

Мовна модель є ненадійним щодо повноважень компонентом. Зміна її промпту або постачальника не змінює правових дозволів. Будь-яка привілейована дія проходить незалежну перевірку.

## Модулі й стандарти

Початковий технічний напрям: HTTP API з OpenAPI, JSON Schema 2020-12 для структур даних, CloudEvents для федеративних подій та відокремлені механізми цифрової довіри.
