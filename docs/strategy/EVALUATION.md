# UAGP Living Practice 90 – протокол незалежного оцінювання

## Перед стартом

Незалежний від щоденного керування координатор переглядає гіпотези, визначення метрик, вибір спільнот, ризики витоку даних та правила припинення. Протокол погоджується до збору результатів, щоб не підганяти критерії під успіх.

## Мінімальна таблиця вимірювань

| Поле | Зміст |
| --- | --- |
| community_code | Псевдонімна спільнота без реєстру учасників |
| initiative_code | Код суспільної ініціативи |
| eligible_for_review | Так/ні, за попередньо визначеною датою |
| steward_assigned | Є реальна відповідальна роль, так/ні |
| meaningful_feedback | Людина отримала змістовну відповідь та наступний крок, так/ні/невідомо |
| days_to_feedback | Дні від погодженого публічного старту до змістовної людської реакції |
| lost_status | Немає відповідального/дії/пояснення, так/ні |
| used_ai_mode | AI / без AI / змішаний, без назви персонального акаунта |
| verifiable_outcome | Підтверджений результат / мотивована відмова / перешкода / невідомо |
| source_ref | Дозволене публічне джерело або локальний доказ із контрольованим доступом |

Не публікувати пов'язані з цими полями ПІБ, персональні контакти, IP, повні тексти чатів чи інші ідентифікатори.

## Методологія

На днях 15–30 заміряти вихідну практику; не припускати, що вона погана. На днях 31–75 повторювати вимірювання за однаковою методикою. Якщо контрольної групи немає, **не стверджувати доведеної причинності**: можна описати спостережуване покращення й альтернативні пояснення, але не приписувати всі зміни UAGP.

Публікувати чисельник і знаменник кожного показника, перелік пропусків, нерозглянутих справ і випадків, коли учасники відмовилися від участі. Негативні наслідки відображати з тією самою ретельністю, що й успіхи. Рецензент отримує доступ лише до даних, які має правомірно переглядати.

## Незалежний висновок

За підсумками рекомендується одне з трьох рішень: **continue**, **redesign** або **stop**, зі списком зауважень меншості. Відсутність реальних партнерів або неприйнятний ризик є легітимним результатом етапу і не приховується.

## Умови безпеки

Порушення приватності, спроби маніпуляції, використання справжніх адміністративних справ без належної підстави або тиск на учасників зупиняють відповідний сценарій. Далі проводиться розбір інциденту, і лише після рішення відповідальних людей можливе відновлення.
