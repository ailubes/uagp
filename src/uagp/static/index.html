01 / 03 · ПІДГОТОВКА

Ваша пропозиція

Попросіть власного асистента створити JSON через інструмент prepare_civic_proposal. Скопіюйте поле handoff або весь результат у форму. Модельні ключі тут не потрібні.

Підключення MCP виконується у вашому AI-клієнті. Цей портал не запитує його пароль, API-ключ або доступ до історії чатів.

Ви можете сформулювати ідею вручну. Далі обидва маршрути працюють однаково.

Лише автор може підтвердити текст. Публікація має окремі умови та контроль.
