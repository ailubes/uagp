# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Confirmed by the project owner: Next.js and TypeScript. Standalone app in web/, separate from the experimental FastAPI Citizen AI prototype.

## Users
Ukrainian residents, civil society groups, municipal officials, researchers, legal reviewers, designers and software contributors. Reading and discovery must not require a GitHub account, an AI subscription or technical literacy.

## Product Purpose
Протокол алгоритмічного врядування України (UAGP) is a public collaboration workspace for the open research initiative. Find real questions, inspect proposed changes, read the Charter, and understand one concrete voluntary next step.

## Positioning
A source-grounded collaboration engine, not a marketing landing page, an official government portal or a political party. Issues and pull requests have different meanings. The site must not create fake participation statistics or decisions.

## Operating Context
Repository: ailubes/uagp. WEB-001 (#29), Participation Steward (#22), independent self-hosted OIDC (#14), Living Practice 90 (draft PR #24), articles 88-1 and 88-2 (draft PRs #21 and #23). Published drafts are explicitly distinguished from merged documents. GitHub remains the initial public source of truth.

## Capabilities and Constraints
First iteration: public read-only workspace, searchable catalogues, item detail, source-grounded documents, role-based contribution routes and private local drafting. GitHub is required only for actions that take place on GitHub. The site has no native write permissions, no accounts, no intake of private administrative cases, no analytics or tracking, and no embedded demo tokens. Independent OIDC, native participation, remote MCP and Participation Steward are later phases subject to privacy/security review.

## Brand Commitments
User-approved Ukrainian name and a restrained technical workspace in the spirit of Linear and GitHub; no copying proprietary visual assets. Ukrainian is the default language.

## Evidence on Hand
Actual public GitHub issues, pull requests, Markdown documents and source timestamps. The initial cached data is an explicitly dated verified snapshot of the public repository. No claimed partners or completed pilot results.

## Product Principles
- Meaningful participation rather than follower counts.
- Real source status rather than synthetic progress.
- Read without account; write only with explicit human confirmation.
- Co-develop tools with existing civic practice; do not force a platform.
- Distinguish project research from legal authority.

## Accessibility & Inclusion
Responsive, keyboard-accessible, plain-language Ukrainian interface. WCAG 2.2 AA is a target to be checked, not a certification. No mandatory AI usage.
