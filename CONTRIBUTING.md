# Як долучитися до UAGP

Ми розробляємо відкритий протокол федеративного алгоритмічного врядування, а не централізовану систему автоматичного ухвалення державних рішень. Участь відкрита для програмістів, дослідників, юристів, фахівців із цифрових прав, кібербезпеки, місцевого самоврядування та всіх, хто готовий аргументовано працювати над концепцією.

## Початок роботи

1. Прочитайте [README](README.md), [Хартію](docs/charter.md), [архітектуру](docs/architecture.md) та [план](docs/roadmap.md).
2. Перевірте [відкриті завдання](https://github.com/ailubes/uagp/issues). Якщо вашої теми немає, створіть issue з описом проблеми, бажаного результату та підстав.
3. Для зміни документації або коду створіть окрему гілку і Pull Request із коротким поясненням причин, альтернатив і способу перевірки.
4. Для питань, що зачіпають права громадян, компетенцію органів або безпеку, обов'язково наведіть ризики та план контролю.

## До внесення коду

Насамперед потрібні вимоги, перевірні контракти й тести. Нові функції не повинні мати прихованих мережевих дій, прямого доступу LLM до привілейованих інструментів, реальних персональних даних або несанкціонованої інтеграції з державними реєстрами.

## Правило для Pull Requests

Опишіть проблему, сценарій застосування, зміни, тести, наслідки для прав і приватності, сумісність із наявними схемами та питання, які залишилися відкритими. Для змін Harness обов'язково визначте, які дозволи змінюються і хто юридично має право їх затвердити.

## Обговорення та прийняття рішень

Заохочуються коректна критика, альтернативи та міждисциплінарна дискусія. Злиття Pull Request означає лише прийняття зміни до проєкту UAGP, а не затвердження державної політики або правового акта.

## Ліцензія та зовнішні внески

Правовий режим коду й документації поки не визначено. До затвердження ліцензій нові автори повинні окремо погодити з власником репозиторію умови використання своїх внесків. Зовнішні Pull Requests можуть обговорюватися, але не повинні зливатися на умовах, які не визначені й не погоджені.

## Code of Conduct

Працюємо предметно: без особистих нападів, переслідування, розголошення приватних даних, дискримінації чи погроз. Суперечки розв'язуємо через аргументи, задокументовані рішення й належний розгляд.
