# Licensing policy for UAGP

**Code:** Apache License 2.0 ([LICENSE](LICENSE); SPDX `Apache-2.0`). This covers original code in `src/`, `tests/`, CI/workflow/configuration files, executable examples, and machine-readable schemas in `specs/`, unless an individual file states different terms.

**Written materials:** Creative Commons Attribution 4.0 International ([LICENSE-DOCS.md](LICENSE-DOCS.md); SPDX `CC-BY-4.0`). This covers original Charter drafts, RFC narrative, public guides, website prose and Markdown community templates.

**External sources:** Licenses above cover only contributions for which the authors have permission. Links to law, standard documentation, external research, existing Google Docs or third-party images do not transfer their copyrights. Individual copyright notices and third-party notices prevail where applicable.

**Contributions:** Contributors retain their copyrights. When proposing work for incorporation, they must be authorized to grant the appropriate license. Do not submit confidential materials or third-party documents without rights. For a code contribution accepted into UAGP, inbound terms match Apache-2.0; for text incorporated into our original documentation, inbound terms match CC BY 4.0. Maintainers should ask explicitly if the contributor's authorization is unclear.

**Issue discussions:** Public Issues and comments are visible to all, but a comment or suggestion is not automatically treated as permission to relicense a separate external copyrighted work. Before incorporating substantial user-submitted text into licensed documentation, obtain the author's express agreement with the applicable terms.

**Authority:** None of these licenses provides a legal right to use public institutions' names, issue binding administrative decisions, or imply that UAGP represents the Ukrainian state.

**Version:** Initial policy, 22 November 2026. Material contributions and rights must remain auditable in Git history.
