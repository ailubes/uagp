# Безпека та відповідальне повідомлення

UAGP поки є дослідницьким проєктом. Жоден компонент не призначений для виконання реальних владних операцій або обробки реальних адміністративних справ.

## Повідомлення про вразливості

**Не публікуйте експлойти, секрети, персональні дані або неперевірені твердження про реальні державні системи в публічних Issues.**

Для приватного контакту використовуйте GitHub Security → **Report a vulnerability**, якщо власник репозиторію ввімкне Private Vulnerability Reporting. До активації такого каналу не передавайте чутливі технічні подробиці через публічні issue; зв'яжіться з maintainer через безпечний канал, узгоджений окремо.

## Базові принципи

- Ніяких реальних ключів і токенів у Git.
- Ніякого прямого доступу LLM до секретів, сховищ чи привілейованих інструментів.
- Заборона за замовчуванням, незалежний ToolGateway, підписані політики та журнал аудиту.
- Ніяких приватних чатів чи персональних даних у публічних подіях федерації.
- Демо-дані та фіктивні повноваження замість реальних державних операцій.

Перед будь-яким пілотом із реальними людьми потрібно окремо визначити модель загроз, правову підставу обробки даних, відповідальних операторів, процедуру реагування на інциденти й незалежне тестування.
